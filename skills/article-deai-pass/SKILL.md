# 文章去 AI 味检查

## 前置（不可跳过）

1. **完整读一遍 `AGENTS.md` 的「写作风格要点」全部条目**——禁止凭记忆。
2. 完整读一遍目标文章。

> ⚠️ **每次病灶都在换地方**，已连续验证五轮：
> 第一轮是「不是 A 是 B」对句 + 比喻自成一段；第二轮是引用排成一列 + 三连排比 + 小节内「先／再／最后」；第三轮（10-11 上午）是「宣布我在感受」（我记了很久／我这边看到的）；第四轮（10-11 晚）是「宣布论证动作」（他再往下走一步／问题在这儿／文章里有个比方）；**第五轮（10-11 夜）是「搬运句式」——把抽象概念当实物搬（把意义从宗教手里挪出来，放进了工作里），一句话打包整个概念**。
> **不要照上一轮的清单查。** 重新通读旧文找感觉。
>
> 最近三轮（10-11 上午／晚／夜）连着出的都是同一类：**不提供信息、只做宣告或打包的句子**——宣布自己在感受、宣布原文在推进、用一个漂亮的比喻把整个概念一句话说完。拿到一句觉得别扭的话，先问：它给了读者什么新东西？

## 流程

1. 跑机械扫描：

   ```bash
   python3 <本 skill 目录>/scripts/scan.py posts/<目录>/<文章>.md
   ```

   脚本只读，输出分段字数、八类病灶命中（带行号）、冒号前半句清单、顿号列举、中英空格、引号、一节内同词重复。

2. 逐条判断命中项，改。
3. 复跑扫描确认清零。
4. `git add` + `commit`，**不 push**。message 前缀用 `🦞claw:style:`。

## 三条最好用的判据

1. **冒号或逗号前面那半句，删掉之后意思完全不变，就删掉。**（命中率最高，覆盖大多数路标句）
2. **这句里有没有新信息？** 只在宣布「注意，接下来要 X」的，删。没有主语变化的（「工作给了一套非常明确的指标：绩效、薪资……」）是陈述 + 列举，留。
3. **分级词看带不带内容**：「还有一层是组织。」留（「组织」本身就是新信息）；「更难的一层是，这种怀疑……」删（只做分级，不提供内容）。

## 改法示例

| 类型 | 原句 | 改法 |
|---|---|---|
| 宣布论证动作 | 他再往下走一步：知识工作本身正在变得空洞。 | 知识工作本身正在变得空洞。 |
| 宣布打比方 | 文章里有个比方：体育裁判的鹰眼技术。错判…… | 体育比赛里引入鹰眼技术之后，裁判的错判少了很多。错判…… |
| 宣布原则 | 有一条原则值得守住：可以让 AI 替你完成工作…… | 可以让 AI 替你完成工作…… |
| 宣布后果 | 时间长了会有一个后果：我们越来越擅长…… | 时间长了，我们越来越擅长…… |
| 宣布感受 | 织毛线这件事我记了很久。 | （整段删——「我记了很久」是替他编的） |
| 搬运句式 | 过去几十年，美国人把意义这件事从宗教手里挪了出来，放进了工作里。 | 他讲的是美国：上教堂的人越来越少。自己是谁，属于哪儿，日子过得有没有意义，这几样过去由教会、家庭、社区管着，现在越来越要靠工作来给。 |

比喻不要宣布，直接陈述事实。

**打包句式的通用改法**：把一句话拆成几句，按「谁、在哪儿、什么时候 → 原来归谁管 → 现在归谁管」平铺，概念自己会浮出来。同时检查同一节内这个概念有没有换个说法被说了第二遍、第三遍（按第 36 条只留一处）。

## 提交前必查（硬错误）

- **frontmatter**：他手改后常变回 `\---` 加行尾双空格，要修回干净的 `---`。
- **中英空格**：手写的新段落最容易整段漏。
- **同音字**。

## 改完要更新

- 文章目录下的 `memo.md`：本轮改了什么、为什么、被他点名的原句。
- `.workbuddy/memory/YYYY-MM-DD.md`：当天日志。
- 新发现的病灶类型写进 `AGENTS.md`（新条号）+ `.workbuddy/memory/MEMORY.md`。
