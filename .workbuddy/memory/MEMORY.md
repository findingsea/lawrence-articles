## 写作风格（持续从执行型反馈中学习）

- 路标式元叙述（先说X/再说Y/我的答案是/说点自己的）是 AI 味，段落直接进入内容。
- 「攒东西」「不是白干的」不是他的用词；「积攒经验」可以。「装进脑子」他自己会用——排斥的是别扭的句子结构，不是具体某个词。
- 他给的替换文本直接照用，不要自由发挥。
- 写「知识进入脑子」类概念时参考《怎样才能记住自己读过的书呢》的动词习惯：放、进、经过、沉淀。
- 不要发明机理阐释（如「模型对一般代码的推测」这种理论化解释），直陈事实：直接给答案、跳过学习步骤、有时是错的。「训练」是他的用词。
- 段首句与段落内容精确对齐，不拔高：讲态度就说「态度会很不同」，不写成「用出来的东西完全不同」。
- 他的口语节奏：「有的时候甚至……也是……」。
- 我反复犯的四条（按频次）：① 发明机理阐释和比喻（直陈事实）② 段首句拔高 ③ 段尾节尾提炼金句 ④ 同一说法跨节重复。
- **说「AI 味重」时，病灶每次都在换地方**（2026-09-30 两轮验证）：第一轮是「不是 A 是 B」对句 + 比喻自成一段展开 + 每段末尾收判断；第二轮是连续引用排成一列（像文献综述）+ 三连排比 + 小节内「先／再／最后」的清单路标。**每次都要重新通读旧文找感觉，不能照上一轮的清单查。**
- **AI 味最集中的形态：「不是 A，是 B」破立对句**（2026-09-30 审《下坡要开心》数出 11 处）。伴随的还有：比喻自成一段展开讲、每段末尾收一句判断小结、排比三连。详见 AGENTS.md 第 29a 条。
- **判断一篇文 AI 味重不重，先数具体的人和事**：他的文章里满是具体动作（翻 git 记录、贴日志、周会、两小时对齐会），抽象叙述一多就露馅。这条比任何形容词层面的调整都管用。
- **结尾要有实质论证，不要停在个人姿态**：他要的不是「个人化」，是有信息量。禁止的是空洞升华，不是论证推进。（《AI 时代的成长困境》定稿时确认）
- 对比写在「过程和成本」上，不比结果；「获取成本」这类维度他会自己补。
- **第一人称不要用「我 + 身份 + 这些年/十来年」**（2026-09-30 明确否掉「我带团队这些年」）：用转变节点式开头，如「转型做管理之后」「入行之后的那些年」。详见 AGENTS.md 第 44 条。
- **他手改时最常动的是「量」**：删掉「我感受最深的」这类抬高、删掉「包括我自己」这类拉近插入语、把「几个同事/他们」改回「一个同事/他」。给他补第一人称细节时，宁可朴素、宁可单数，不确定的具体信息先问，不要自己加量。（2026-09-30 学自 diff，AGENTS.md 第 45 条）
- **「呆板」指的是句式，不是嫌抽象**（2026-10-05 学自 diff，纠正前一版）：他说某段「太呆板」时，我上一轮把概念词换成了口语绕述，他拿到手又自己换回了术语——「不过脑子就出来了」→「这是一种向内归因」、「不像一句信念，更像一条常识」→「在过去是一种政治正确」。**他不排斥概念词，排斥的是对句、排比、判断句连排。**遇到「呆板」先改结构，不要顺手把话说浅（AGENTS.md 第 48 条）。
- **他手改时会删的两类句子**（2026-10-05）：① 独立成段的「我觉得……是这么来的」提炼句，尤其是自己发明的比喻（「连本来该是下坡的那几段，也被当成坡在爬」）；② 为下一节预埋的钩子（项飙那条「经济上行时还能运转、放缓后开始伤人」，实际是给第五节铺路）。观察摆完就停（AGENTS.md 第 49 条）。
- **不要借行当语汇做比喻**：写「开心没练过」，我写「手是生的」，他改成「不知从何用起」。状态直陈（AGENTS.md 第 50 条）。
- **不要自己造概念词**（2026-10-07）：我写「下坡是在掉东西」，他判「太难以理解」——中文里「掉东西」第一义是丢东西，而且我把它名词化后反复用，越用越像术语。**造词只在写作者自己脑子里统一，读者没有这个上下文。**要么用现成的词（优绩主义、向内归因），要么直接说事。他定下的概念词直接照用，不要自己换回通用说法。（AGENTS.md 第 51 条）
- **删的是「宣布转折」的路标句，留的是承担推理的连接词**（2026-10-07 第二次手改）：他删掉了「麻烦在于，」「再往外看一层，」「这两条线是叠在一起的……」「他们感慨的是另一件事：」，但保留「到了某个点，增速会下来」这类陈述事实的句子；同时他自己会用「之所以……也是因为」「从而」「更多的是要」这类书面因果连接。**我以前把连接词和路标一起清了，清过头。**（AGENTS.md 第 52、53 条）
- **他不要跟读者辩论**：「这个区分有必要较真……既然是技术带来的，那也能靠技术绕开。其实绕不开。」整段被删——先立想象中的反驳再驳倒，是辩论腔。（AGENTS.md 第 54 条）
- **他要「分成几个方面」时，就标序号——但序号要单起一段**（2026-10-09 手改纠正）：我在《下坡要开心》第六节把三方面写成自然段落、不加序号，他改成「首先，是心态要接受。」／「其次，要积极地做一些适应性改变。」／「最后，也是最重要的，学会自我调节。」各占独立一段，内容跟在后面。跟「反路标」不矛盾：反的是流动叙述里宣布转折的空句子，不是主动分类时的结构标示。判断办法——这一节是不是在明确回答「分几个方面」，是就标。AGENTS.md 第 56 条。
- **先摆具体观察，结论句放在后面而且要短**（2026-10-09 他重写第一节）：旧稿「最近一个很明显的感受是，当前是一个往下的氛围 + 举例」，他改成两段对话并列摆完，才给「一个很明显的感受就是：大家都明显没有以前开心了」。判断句不要长过观察。续貂：两段观察之间他用一个虚词「也」接住，不写解释句。详见 AGENTS.md 第 58 条。
- **「具体」指的是那句原话本身，不是我给对话补的身份背景**（2026-10-10 手改）：他把「他也才二十几岁，在一个不算差的行业里，做着一份还算稳定的工作」整句删掉，换成「整体的情绪就比较丧」。他要的是对话里的那句「干一天是一天」+ 一句情绪判断，不要我替读者补年龄、行业、稳定性这些信息。
- **禁止宣布「我在感受／我在观察」**（2026-10-11 他点名两条，判「非常典型的 AI 味」）：「织毛线这件事我记了很久」「我这边看到的」都被否。这类句子不提供信息，只宣布作者的心理状态或即将给出的视角。禁用形态：我记了很久／我印象很深／我读的时候一直在想／我这边看到的／我注意到／让我……/ 值得思考的是。小标题同理，要说内容（改「我理解的工作主义」）。同源的「真正要问的是：」「最微妙的地方在这儿：」「关键在另一件事：」跟第 52 条他删过的「他们感慨的是另一件事：」一族，删冒号前半句。⚠️ 加重：**不许替他编感受**——「我记了很久」和「学陶艺、学钩织」他都没说过，第 2 条（不许构造没经历过的场景）同样适用于心理活动（AGENTS.md 第 59 条）。
- **禁止宣布论证动作与结构**（2026-10-11 他点名「他再往下走一步」，判「也是非常典型的 AI 味的表述」）：跟「禁止宣布感受」那一条同族，主语换成「他／文章／这里」。禁用：他再往下走一步／往下推／再往下一层／问题在这儿／这里的分界是／文章里有个比方／具体的样子是这样的／有一条原则值得守住／会有一个后果。**判据最好用：冒号或逗号前面那半句，删掉之后意思完全不变就删掉。** 要留的是「陈述 + 冒号 + 列举」（「工作给了一套非常明确的指标：绩效、薪资……」），前半句有实义。比喻不要宣布，直接陈述事实（「文章里有个比方：鹰眼」→「体育比赛引入鹰眼技术之后，裁判的错判少了很多」）（AGENTS.md 第 60 条）。
- **解释一个概念不要用「搬运」句式一句话打包**（2026-10-11 他点名「过去几十年，美国人把意义这件事从宗教手里挪了出来，放进了工作里。」，判「也很 AI 味」，要求「用平实朴素的语言解释一下这个概念的起源」）：病灶是**把抽象名词当成可以搬运的实物**——把 X 从 A 手里挪出来、放进 B 里 / 把 X 装进 Y / 「……全在里面」。一句话说完整个起源，读者拿到的是漂亮的总括，不是具体的事。**改法：拆成几句，按「在哪儿、什么时候 → 原来归谁管 → 现在归谁管」平铺**，概念自己会浮出来。改成「他讲的是美国：上教堂的人越来越少。自己是谁，属于哪儿，日子过得有没有意义，这几样过去由教会、家庭、社区管着，现在越来越要靠工作来给。」**顺带要清重复**——那段把「宗教→工作」说了三遍，按第 36 条只留一处；概念解释最容易换个说法再说一遍。小标题同理，不要替概念做总结（「workism：意义是怎么装进工作的」→「workism」）。AGENTS.md 第 61 条。
- **连续三轮（10-11 上午／晚／夜）病灶都是「不提供信息，只做宣告或打包」**：宣布我在感受 → 宣布原文在推进 → 用比喻打包概念。拿到一句觉得别扭的话先问：它给了读者什么新东西？
- **排比三连他自己会用，不是禁区**（2026-10-09）：他手改时新写了「不要自己内耗，不要把精力花在对抗环境上，更不要把精力花在怨天尤人上」「环境在变，公司在变，规则在变」。成片出现或三项互相凑数才是 AI 味。AGENTS.md 第 57 条。

## 写一篇文章的完整流程

- ⚠️ **框架必须先单独过一遍，他确认后再写正文**（2026-10-10 他明确：「以后文章框架先跟我讨论下，再写」）。做法：选题敲定 → 出框架（分几节／每节的推演线／开头用哪件真事／结尾推进到哪一层）→ 他确认 → 才起草。我此前直接写完整稿，第一稿被否（`45a5829`）。详见 AGENTS.md「动笔前必须先过框架」。**框架里不许替他构造我没经历过的具体场景——开篇素材必须来自他给过的真事。**

- **全流程复盘（选题 → 框架 → 起草 → 引用核实 → 三轮 AI 味重写 → 结构调整 → 七轮手改 → 封面与索引）见 AGENTS.md「协作写作流程」下的「一篇长文的完整周期（《下坡要开心》复盘）」**（2026-10-10 汇总）。
- 一句话版：起稿就按 3000 以内写；字数不够用素材补，不用形容词补；他每次说「AI 味重」病灶都不同，重新读旧文别照旧清单；手改一律照字面收，只修硬错误；每轮必查 frontmatter、中英空格、同音字。

## 协作方式（2026-09-10 从《AI 时代的成长困境》定稿总结）

- 先讨论框架和角度，再动笔；他给执行型反馈，替换文本照用。
- 他手改一节后，要回头检查相邻章节有无指代悬空。
- 我标注「存疑但保留」的句子，他没删不等于认可，应主动指出。
- 数据必须有一手来源，验证后往往不用删，反而更扎实。
- 结构原则：先讲机制再讲问题；一节只走一条推演线；不写管理指南（写一线观察）；不用我的推论冒充他的观察。
